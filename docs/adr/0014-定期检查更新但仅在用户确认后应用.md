# 定期检查更新但仅在用户确认后应用

Skill Router 只在应用运行时检查外部来源：启动时检查一次，之后每 24 小时最多自动检查一次，并允许手动刷新；不安装 LaunchAgent，也不在应用退出后后台运行。发现更新时只在应用侧边栏“更新”显示徽标并列出可更新项，不申请系统通知权限或弹出模态框。用户按套件或独立 Skill 分别确认后才更新中央库；首版不展示内容变化、被删除 Skill 或受影响项目，不支持套件内逐 Skill 更新，也不强制一次更新全部来源。相比持续后台更新，这避免来源在无交互时改变所有项目并减少后台生命周期；相比提供完整变更预览，这降低了首版实现范围，但用户确认时并不知道具体影响，且确认后的来源移除仍会按既定规则级联修改项目清单。
