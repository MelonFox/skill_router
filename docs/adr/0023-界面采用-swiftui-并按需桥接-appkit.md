# 界面采用 SwiftUI 并按需桥接 AppKit

Skill Router 的导航、列表、详情、表单和状态驱动界面使用 SwiftUI，实现不足的 macOS 能力再局部桥接 AppKit，例如系统文件选择面板。首版不提供应用内 Skill 创建向导或编辑器，用户在应用外创建和编辑后通过本地目录导入；应用只负责查看、定位和管理。相比纯 AppKit 或大规模混合，这能缩短首版界面开发周期并维持单一状态模型；代价是少数桌面交互可能受 SwiftUI 能力限制，需要用窄范围适配层补足。

一级导航、详情呈现和组件复用方式已由 [ADR-0037](./0037-原生界面采用三级导航与统一组件.md) 修订；本 ADR 继续作为 SwiftUI 与 AppKit 技术边界的依据。
