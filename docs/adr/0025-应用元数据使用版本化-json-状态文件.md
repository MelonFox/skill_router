# 应用元数据使用版本化 JSON 状态文件

Skill Router 将来源 URL、套件映射、项目注册、目标配置和更新时间等应用元数据保存在带 `schemaVersion` 的 JSON 状态文件中，原生应用与 CLI 通过同一个排他文件锁协调，并使用同目录暂存加原子替换提交修改；写操作最多等待约 5 秒，超时返回明确的“Skill Router 正忙”非零退出码，不无限等待，也不把请求转发给后台服务。Skill 内容仍直接保存在中央库文件系统。相比 SQLite 或 SwiftData，这更容易检查、备份、测试和跨进程复用；代价是复杂查询与并发写入能力有限，所有写操作必须遵守同一锁和完整文件提交协议。
