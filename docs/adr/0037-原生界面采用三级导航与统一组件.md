# 原生界面采用三级导航与统一组件

Skill Router 的一级侧边栏固定为“技能、项目、设置”。来源更新和系统 Skill 仍保留完整能力，但作为低频管理功能归入设置，不显示侧边栏更新徽标；主题也只在设置中选择。技能与项目页面共用页面标题、图标操作、搜索、筛选、面板、实体行、状态、空态、详情弹窗和反馈组件。条目详情点击后以弹窗显示，不在主区常驻；低频或破坏性操作放在详情的“更多”菜单。

应用采用自定义 SwiftUI `HStack` 外壳、固定侧边栏和圆角内容面板，支持跟随系统、浅色和深色外观。视觉以系统字体、SF Symbols 和中性灰阶为主，不使用蓝色作为品牌主操作色。页面差异通过公共组件参数和 `ViewBuilder` 插槽表达，单次使用的业务视图不为追求复用而抽象。

状态按职责拆成全局应用、技能、项目和设置四层，并通过可注入的应用服务调用既有 `SkillRouterCore`。该决定不修改核心领域模型、磁盘布局、CLI 或 JSON 契约。它取代 ADR-0023 中“五个一级页面”和常驻列表—详情结构的部分，保留 ADR-0023 对 SwiftUI 为主、AppKit 窄范围桥接的决定。
